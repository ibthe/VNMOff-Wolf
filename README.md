# VNMOff Wolf (Android)

Приложение голосовых заметок на базе [Voice Notes Wolf](https://github.com/ibthe/Voice-Notes-Wolf).
Отличие от оригинала: перевод текста выполняет **MADLAD-400 3B-MT** (int8, ONNX Runtime)
прямо на телефоне, вместо Google ML Kit / Google Переводчика. Текст для перевода никуда не отправляется.

Приложение ставится **рядом** с оригиналом: `applicationId` `app.vnowolf`, имя «VNMOff Wolf»,
своя иконка (волк со звуковой волной). Данные, настройки и модели у приложений раздельные.

## Требования к телефону
Перевод использует около 3 ГБ файлов модели и заметный объём оперативной памяти.
Реалистично: arm64, 8 ГБ ОЗУ и больше, около 4 ГБ свободного места. На слабых телефонах приложение
может закрываться при первом переводе.

## Сборка
1. **Один раз** запустите GitHub → Actions → **Publish models** → Run workflow.
   Он выложит в релиз `models` модели распознавания и перевода (около 4 ГБ суммарно).
   Экспорт MADLAD 3B тяжёлый (нужно примерно 32 ГБ ОЗУ и 35 ГБ диска): на обычном `ubuntu-latest`
   он может не поместиться. Тогда укажите в поле `runner` больший раннер либо выполните
   `python tools/export_madlad.py out/` у себя и загрузите файлы `out/madlad-*` в релиз `models` вручную.
   Репозиторий должен быть публичным: приложение качает модели по обычной ссылке.
2. APK собирается при каждом push в main (Actions → **Build VNMOff Wolf APK**).
   Готовый файл: **Releases → latest → VNMOff-Wolf-debug.apk**.
3. После установки: меню → «Модели распознавания». Для перевода нужен набор
   **«Перевод (MADLAD-400, 3B)»** (около 3,3 ГБ, скачивается один раз, докачка поддерживается).
   Если репозиторий переименован, поправьте `BASE_URL` в `speech/ModelStore.kt`.

## Как работает перевод
- `translate/MadladTokenizer.kt` — SentencePiece Unigram (Витерби) по словарю `vocab.tsv`; в начало входа
  ставится тег целевого языка (`<2ru>`, `<2en>`, `<2ka>`), код исходного языка модели не нужен.
- `translate/TextPreprocessor.kt` — очистка текста перед переводом (дубли знаков, «э-э», запинки,
  сленг «щас/чё/норм», gonna/wanna) и разбиение длинных предложений (>20 слов) на фразы.
- `translate/TextTranslator.kt` — энкодер + декодер T5 с кэшем ключей/значений, лучевой поиск (2 луча),
  штраф за повторы 1.1, запрет повторов триграмм, нормализация по длине. Параметры в `companion object`.
- `tools/export_madlad.py` — экспорт модели в ONNX и квантование int8 (веса во внешних `.data`-файлах).
- Языки: русский, английский, грузинский; перевод напрямую между любой парой.
- Модель грузится при первом переводе и выгружается из памяти через 90 секунд простоя.
